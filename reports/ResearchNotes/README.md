# 연구노트

블로그 사이드바의 **연구노트** 그룹에 표시되는 페이지 모음입니다. 메뉴 항목은 저장소 루트의 `manifest.json`에서 관리합니다.

| 페이지 | 파일 | 최신 반영 자료 |
|---|---|---|
| TDS, ISTD 영향 | `tds_istd.html` | v1 · 2026.10.28. 진행 상황 보고 |
| NUPIC 개념 설명 | `nupic.html` | NRC 공개 문서 29건 (2026-11-06) |

NUPIC 페이지의 첨부 PDF는 모두 NRC ADAMS 공개 문서라서 `nupic_refs/`에 원문을 함께 올립니다.
(`vir/` 벤더 검사보고서, `imc/` 검사매뉴얼, `ip/` 검사절차)

## 새 데이터가 들어왔을 때 업데이트 절차 (TDS, ISTD 영향)

1. 새 자료(PDF·엑셀 등)의 결과를 `tds_istd.html`의 해당 섹션(01~05)에 반영하거나, 새 단계 결과면 섹션을 추가합니다.
2. **06 비판적 검토**: 새 데이터로 해결된 항목은 "해결됨(vN)"으로 표시하고, 새로 생긴 의문은 C9, C10… 으로 추가합니다.
3. **07 추가해야 할 연구**: 완료된 항목을 표시하고 우선순위를 다시 정합니다.
4. **08 업데이트 로그**에 날짜·버전·반영 자료·변경 내용을 한 줄 추가합니다.
5. 머리말의 "최신 반영 자료"와 "마지막 업데이트", `manifest.json`의 `date`를 갱신합니다.

원본 보고자료(PDF)는 저장소에 올리지 않고, 요약·그래프·검토만 게시합니다.
